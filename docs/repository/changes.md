# Changes, Commits, And PRs

Use Conventional Commits checked by Commitizen.

## Commits

Keep subjects short, imperative, and meaningful:

- `feat: add vscodium home module`
- `chore: update desktop settings`

Prefer brief bodies only when they clarify intent or validation. Keep commits
focused by host, module, or overlay.

## Pull Requests

Include:

- Intent.
- Affected paths.
- Commands run.
- Manual validation.
- Whether the change was built only or switched locally.

Include screenshots only for visible desktop or application changes.
